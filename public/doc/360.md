# Photo Sphere Viewer — Khái niệm & Vòng đời

## 1. Yêu cầu ảnh đầu vào

PSV chỉ render được ảnh **equirectangular** — ảnh toàn cảnh cầu trải phẳng.

| Thuộc tính | Yêu cầu |
|---|---|
| Tỉ lệ | **2:1** bắt buộc (ví dụ: 4096×2048, 6000×3000) |
| Format browser | JPG, PNG, WebP (KHÔNG dùng EXR, HDR, RAW) |
| Kích thước tối thiểu | 2000px chiều rộng để không bị vỡ hạt |
| Nguồn gốc | Camera 360° thật, render từ phần mềm 3D, hoặc convert từ HDR qua ffmpeg |

**Nếu ảnh không phải equirectangular:** viewer sẽ render ra hình méo mó, hoặc không kích hoạt `ReadyEvent` → loading mãi.

**Nếu ảnh là EXR/HDR:** browser không đọc được định dạng này. Cần convert trước:
```bash
ffmpeg -i input.exr \
  -vf "tonemap=hable:desat=0,format=yuv420p" \
  -frames:v 1 -update 1 -q:v 2 output.jpg
```

## 2. Vòng đời của Viewer

```
new Viewer({ container, panorama, ... })
    │
    ├─► [Constructor] Khởi tạo Three.js scene, WebGL renderer, camera
    │       Nếu WebGL không khả dụng → throw Error → bắt bằng try/catch
    │
    ├─► [Async] Tải ảnh từ URL (HTTP request)
    │       Nếu 404 hoặc lỗi mạng → PanoramaErrorEvent
    │
    ├─► [Async] Decode ảnh → tạo texture
    │       PanoramaLoadedEvent ← texture xong, nhưng chưa render ra màn hình
    │
    ├─► [Render] Three.js render lần đầu lên canvas
    │
    └─► ReadyEvent ← viewer THỰC SỰ sẵn sàng, người dùng thấy ảnh
```

### Tại sao phải dùng `ReadyEvent` thay vì `PanoramaLoadedEvent`?

`PanoramaLoadedEvent` fires khi texture được decode xong **trong bộ nhớ GPU** — nhưng Three.js chưa chắc đã render frame đầu tiên ra canvas. Nếu tắt loading overlay ở đây, người dùng sẽ thấy màn hình đen trong vài ms.

`ReadyEvent` fires sau khi frame đầu tiên đã được vẽ xong → người dùng thấy ảnh ngay khi overlay biến mất.

```
PanoramaLoadedEvent  →  ReadyEvent
       ↑                    ↑
  texture ready         frame rendered
  (dùng cho logic)      (dùng cho UI)
```

## 3. Vòng đời khi đổi scene (`setPanorama`)

```
viewer.setPanorama(newUrl, options)   ← trả về Promise
    │
    ├─► Hủy request ảnh cũ nếu đang tải
    │
    ├─► [Async] Tải ảnh mới
    │       Nếu lỗi → Promise reject → bắt bằng try/catch
    │
    ├─► [Async] Decode texture mới
    │       PanoramaLoadedEvent fires
    │
    ├─► Chạy transition (nếu có)
    │
    └─► Promise resolve ← đây là lúc set isLoading = false
```

**Lưu ý:** `await setPanorama()` resolve nghĩa là ảnh đã load và transition xong. Set `isLoading = false` ngay sau `await` — không cần dùng event listener cho lần này.

## 4. Vòng đời của Plugin (MarkersPlugin)

```
new Viewer({ plugins: [[MarkersPlugin, { markers: [...] }]] })
    │
    └─► Plugin được khởi tạo cùng Viewer
          markers render khi viewer ready

viewer.getPlugin<MarkersPlugin>(MarkersPlugin)
    → truy cập instance sau khi Viewer tạo xong

markers.clearMarkers()    ← xóa toàn bộ
markers.setMarkers([...]) ← thêm loạt mới
                          Gọi sau setPanorama() resolve để sync với scene mới
```

## 5. Vòng đời của Component Vue (`useSceneViewer`)

```
setup()
  └─► useSceneViewer(container, scene, onHotspot)
        ├─► isLoading = true  (ref)
        ├─► Đăng ký onMounted → createViewer()
        ├─► Đăng ký watch(scene.id) → updateScene()
        └─► Đăng ký onBeforeUnmount → viewer.destroy()

onMounted
  └─► createViewer()
        ├─► new Viewer(...)
        ├─► addEventListener('ready') → isLoading = false
        └─► addEventListener('panorama-error') → errorMessage = ...

watch(scene.id)
  └─► updateScene(newScene)
        ├─► isLoading = true
        ├─► await setPanorama()
        ├─► isLoading = false  ← sau khi Promise resolve
        └─► update markers

onBeforeUnmount
  └─► viewer.destroy()  ← giải phóng WebGL context, hủy request
        viewer = null
```

## 6. Các lỗi thường gặp

| Triệu chứng | Nguyên nhân | Cách fix |
|---|---|---|
| Loading mãi không tắt | Dùng `PanoramaLoadedEvent` thay vì `ReadyEvent` | Đổi sang `ReadyEvent` |
| Loading mãi khi đổi scene | `updateScene` không set `isLoading = false` sau `await` | Thêm `isLoading = false` sau `await setPanorama()` |
| Ảnh bị méo / distort | Ảnh không phải equirectangular 2:1 | Dùng ảnh đúng tỉ lệ |
| Màn hình trắng / đen | Container có kích thước bằng 0 khi Viewer khởi tạo | Đảm bảo container có `width` và `height` trước `onMounted` |
| EXR không load | Browser không hỗ trợ OpenEXR | Convert sang JPG bằng ffmpeg trước |
| WebGL error | Trình duyệt không hỗ trợ WebGL | Kiểm tra `canvas.getContext('webgl2')` |

## 7. Event quan trọng cần nhớ

| Event | Type string | Khi nào fires |
|---|---|---|
| `ReadyEvent` | `"ready"` | Viewer render xong frame đầu tiên |
| `PanoramaLoadedEvent` | `"panorama-loaded"` | Texture decode xong (chưa render) |
| `PanoramaErrorEvent` | `"panorama-error"` | Lỗi tải hoặc decode ảnh |
| `LoadProgressEvent` | `"load-progress"` | Tiến độ tải ảnh (0–100%) |

```ts
import { Viewer, events } from '@photo-sphere-viewer/core';

viewer.addEventListener(events.ReadyEvent.type, () => { ... });
viewer.addEventListener(events.PanoramaErrorEvent.type, ({ error }) => { ... });
```
